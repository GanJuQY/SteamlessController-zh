# 中文版 SteamlessController —— 安装与说明

这是**汉化过的 SteamlessController 主程序**，在 Linux 上用 MinGW-w64 交叉编译出来的。
上游源码里没有任何语言资源（`app.rc` 连 STRINGTABLE 都没有），界面文字全硬编码在 C++ 和一段内嵌 HTML 里，
所以汉化只能是「改源码 + 重新编译」，不存在外挂式语言包 —— 你手上这个 exe 就是重新编出来的成品。

## 第一版为什么全是乱码（这一版修好了）

第一版「自定义控制」窗口里的字全是 `è‡ªå®šä¹‰æŽ§å¶` 这种乱码。原因在上游代码：
`src/app/RemapWindow.cpp` 的 `GetHtml()` 把内嵌 HTML 从 UTF-8 字面量转成宽字符串时，**一个字节塞一个
`wchar_t`**。上游注释里写得很清楚 —— 「HTML is ASCII-only (JS glyphs use \uXXXX escapes); each byte
widens 1:1」：英文界面全是 ASCII，这么写等于没毛病；文字换成中文（UTF-8 多字节）以后，一个汉字就被拆成
两三个乱码字母。

修法是老实按 UTF-8 解码（`MultiByteToWideChar(CP_UTF8, ...)`，和这个仓库自己读 Steam 路径的
`LauncherGames.cpp` / `SteamAppLocator.cpp` 写法一致），补丁是
`patches/utf8-widen-fix.patch`（发布包里在 `源码与构建脚本/`）（1 个文件、2 处）。托盘菜单、右键菜单、气泡提示不受影响
（那些是 C++ 宽字符串，本来就是对的），所以乱码只出现在网页那部分 —— 和你截图里看到的完全一致。

## 装（3 步）

**1. 先装官方版（v1.24 安装包）**

- 安装包：https://github.com/ddeverill/SteamlessController/releases/download/v1.24/SteamlessController-Setup.exe
- 前置驱动 ViGEmBus 1.22.0（官方安装包会装；没装的话这里下）：https://github.com/nefarius/ViGEmBus/releases/download/v1.22.0/ViGEmBus_1.22.0_x64_x86_arm64.exe

**2. 退出托盘程序**
右下角托盘图标 → 右键 → 退出。不退出的话 exe 被占用，文件复制不进去。

**3. 覆盖这两个文件**（默认安装目录 `C:\Program Files\SteamlessController\`）

| 文件 | 动作 | 说明 |
| --- | --- | --- |
| `SteamlessController.exe` | 覆盖同名文件 | 中文主程序（4.2 MB） |
| `WebView2Loader.dll` | **新增**，别删 | 本版本动态链接它；官方是静态链接，所以官方目录里本来没有这个 DLL |

`SteamlessDeviceCycle.exe`、`ViGEmBusProbe.exe` **保持官方的别动**（这一版没重编它们，官方源里这两个文件与 main 分支逐行一致，混用是安全的）。

## 和官方版有什么不一样

- **中文**：托盘菜单、所有对话框，以及「自定义控制」窗口里整页 HTML/JS（约 1300 个汉字）全部换成简体中文。
  CSS 字体加了 `'Microsoft YaHei UI','Noto Sans SC'` 回退，中文不会掉成方框。
- **唯一功能差异**：商店 / MSIX 游戏（Xbox Game Pass 那类 UWP 包裹的游戏）不会出现在游戏选择器列表里。
  原因：官方用 MSVC 的 C++/WinRT（`PackageManager`）枚举它们，MinGW 没有 C++/WinRT，这段被条件编译掉了
  （`src/app/GameLibrary.cpp` 里 `#ifdef _MSC_VER` 那段）。普通 exe 游戏、Steam 游戏、启动器游戏
  （Epic / Ubisoft / Battle.net / GOG 等）都不受影响。
- **多一个 DLL 依赖**：见上表。该 DLL 取自微软官方 NuGet 包 `Microsoft.Web.WebView2/1.0.2849.39`。
- **版本号显示 1.25**：编的是上游 main 分支（比已发布的 1.24 新一点，多了扳机设置那块）。
  官方安装包写入「应用和功能」里的卸载条目仍是 1.24，不影响使用。
- 「简体中文」只覆盖界面；键盘/手柄按键名、Steam 的 `[PlayStation]`/`[Xbox]` 标记、程序名 `Steamless Controller` 保持原样（那是标识，翻了反而对不上）。

## 验证到什么程度 / 没验证什么

已验证：

- 从干净上游源码 + 三个补丁，脚本一把编出同一个 exe（可复现，`源码与构建脚本/mingw-build.sh`）；
- 依赖干净：只吃系统 DLL + `WebView2Loader.dll`，不依赖 MinGW 运行时（已静态链接 libgcc/libstdc++）；
- wine 下能正常启动并跑进初始化流程（wine 自身缺 `KERNEL32.GetApplicationUserModelId` 才中断，真 Windows 有这个 API）；
- exe 里的中文字符串逐条比对通过：C++ 宽字符串 65 条全中、HTML/JS 片段全部命中；
- 这次针对乱码的修法单独验证过：把真实的 79629 字节 HTML 载荷喂给「旧写法」和「新写法」两种转换
  （在 wine 上跑真实的 `MultiByteToWideChar`）。旧写法 79629 个宽字符、查不到任何中文；
  新写法 77519 个宽字符，`自定义控制`／`重新绑定`／`搜索游戏或程序` 全部命中。

**没验证：真机 Windows + 真手柄。** 如果出问题（比如「自定义控制」窗口白屏、手柄不接管），
把 `%LOCALAPPDATA%\SteamlessController\` 下的日志发我。

## 想自己重编

```bash
bash 源码与构建脚本/mingw-build.sh
```

依赖（Ubuntu/Debian）：`cmake ninja-build g++-mingw-w64-x86-64 mingw-w64-tools curl unzip`

目录里三个补丁（脚本按这个顺序打）：

- `SteamlessController-zh-CN.patch` —— 中文翻译本身（对上游 main；198 条替换全部命中）
- `utf8-widen-fix.patch` —— 修内嵌 HTML 的 UTF-8 解码（`src/app/RemapWindow.cpp` 的 `GetHtml()`，2 处）。
  只编中文版时它是**必需**的；打通用 MSVC 自编也一样要打，否则网页那部分照样乱码
- `mingw-port.patch` —— MinGW 移植，3 个文件：`GameLibrary.cpp` 把 WinRT 那段条件编译、
  `CMakeLists.txt` 把 WebView2 从静态库换成 `WebView2Loader.dll.lib` 并去掉 mingw 没有的 `windowsapp`、
  `RemapWindow.cpp` 补一个 `Microsoft::WRL::Callback` 的等价实现（mingw 的 WRL 只有 client.h/internal.h/module.h，
  没有 MSVC 的 `wrl/implements.h`）
